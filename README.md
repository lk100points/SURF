# SAF SURF

Бесконечный раннер в ночном городе. Управляй персонажем, уклоняйся от полицейских фургонов, собирай пакетики зеленого чая и улучшай свой стиль!

## Технологии
- HTML5 / CSS3
- JavaScript (ES6 Modules)
- Three.js (через CDN importmap)
- WebAudio API (синтез звука без файлов)

## Установка и деплой (GitHub Pages)

1. Создайте новый репозиторий на GitHub.
2. Распакуйте ZIP-архив и загрузите файлы `index.html`, `style.css`, `game.js` и `README.md` прямо в корень репозитория (ветка `main`).
3. Перейдите в настройки репозитория: **Settings** -> **Pages**.
4. В разделе **Build and deployment** -> **Source** выберите `Deploy from a branch`.
5. В **Branch** выберите `main` и папку `/ (root)`.
6. Нажмите **Save**. Игра будет доступна по ссылке через пару минут.

## Управление

### Мобильные устройства (Сенсорный экран)
- **Свайп влево / вправо** — смена полосы.
- **Свайп вверх** или **Тап** — прыжок.
- **Свайп вниз** — подкат.

### ПК (Клавиатура и мышь)
- **ArrowLeft / A** — влево.
- **ArrowRight / D** — вправо.
- **ArrowUp / W / Space** — прыжок.
- **ArrowDown / S** — подкат.
- **Клик мыши** — прыжок.
- **Esc** — пауза / назад в меню.
- **Enter** — подтверждение в меню.

## Особенности
- Процедурная генерация мира и персонажа (без внешних 3D моделей).
- Динамическая сложность (скорость растет).
- Экономика: собирай чай, открывай новые цвета одежды.
- Сохранение прогресса в `localStorage`.
- Оптимизировано для 60 FPS (пулы объектов, фиксированный шаг физики).

☑ 60 fps: фиксированный шаг физики, пулы объектов (чай, машины, барьеры), нет создания new в цикле обновления. Рестарты без утечек (сброс пулов).
